# Gamified-Learning-System
Gamified Learning System: Interactive Quiz Engine with Learning Analytics
## Description
A gamified interactive learning system developed in Unity that incorporates real-time feedback, scoring mechanisms, and user interaction tracking. The system is designed to enhance engagement and evaluate learning performance through structured interaction.
## Features
* Multiple-choice question system
* Real-time feedback (correct/incorrect responses)
* Score tracking and progression system
* Visual feedback (color-coded responses)
* CSV-based logging of user responses and performance
## Research Value
This project enables quantitative evaluation of learning behavior and engagement. It supports research in game-based learning, user feedback systems, and educational performance analytics.
## Tools & Technologies
* Unity (UI System)
* C#
* TextMeshPro
* CSV Data Logging
